# Active V3: cost-aware low-turnover crypto trend

V3 создан после того, как V2 показал положительный base holdout, но отрицательный результат при 20 б.п. на сторону. Вместо повышения риска V3 уменьшает оборот.

## Правила

- BTCUSDT / ETHUSDT / cash, long-only spot, без плеча.
- Сигналы только по завершённым дневным свечам.
- Исполнение по open следующего UTC-дня.
- Dual momentum + EMA regime + volatility sizing.
- Ребалансировка раз в 7 или 14 дней.
- Minimum hold 14/28 дней.
- Порог переключения BTC↔ETH.
- Weight band против мелких пересчётов позиции.
- Отбор одновременно по development/validation при 10 и 20 б.п. на сторону.
