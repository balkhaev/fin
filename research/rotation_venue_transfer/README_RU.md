# Перенос зафиксированной стратегии с Binance на OKX

Исследуется один кандидат из PR127: `guarded_ensemble20`. Его параметры,
источники правил и симулятор не изменяются. Задача — проверить, сохраняется
ли исторический результат на другой площадке, а не подобрать новую удачную
конфигурацию. Это исследование на данных рынка, не запущенный торговый сервис.

Протокол опубликован до получения OKX-цен: commit
`dbb1c520bc689908a1b8e722a668351d7cf2b05d`. Выбор основной модели, девять активов,
периоды, расходы и проверки не зависят от результатов новой загрузки.

## Что сравнивается

Четыре сочетания источника сигналов и места моделируемого исполнения:

| Источник сигналов | Цены исполнения и доступный объём | Назначение |
|---|---|---|
| Binance | Binance | Точное воспроизведение прежнего контроля |
| Binance | OKX | Проверка переноса исполнения при прежних сигналах |
| OKX | OKX | Полный перенос модели на другую площадку |
| OKX | Binance | Проверка влияния источника сигналов |

Это отдельные счета в симуляции, а не реальный перевод денег между биржами,
арбитраж или сложение прибылей нескольких одновременно профинансированных
портфелей. Каждый счёт начинает с 10 000 USDT; никакого плеча и коротких позиций.

Входы, исторический порог оборота, оценка волатильности и рыночный фильтр берутся
с площадки сигналов. Номинальная ликвидность для ограничения исполнения берётся
с площадки исполнения. Поэтому близкие котировки ещё не означают одинаковые
целевые позиции: объёмы торгов на площадках различаются. Порог оборота не
снижается после обнаружения малого количества подходящих активов.

## Источники и время

Binance — точные 990 архивов предыдущего исследования, manifest SHA256:
`da9ca6d1e782e8ef6c816390ef3e6ea363eec53a67f58592a8505d754bf5bfe2`.

OKX — официальный публичный `GET /api/v5/market/history-candles`, `bar=1Dutc`.
Обычный `1D` не взаимозаменяем с сутками UTC. Учитываются только свечи с
`confirm=1`; каждая страница должна идти назад по времени, строго раньше
курсора. Дубликаты внутри страниц и между ними запрещены, целостность каждой
сохранённой страницы сверяется по SHA256. Эти хеши рассчитаны нами: они
удостоверяют неизменность файла, а не подпись биржи и не независимую проверку
точности публикуемых цен.

Для спота `vol` используется как объём базовой монеты, а `volCcyQuote` — как
денежный оборот. Не подставляются фьючерсный контракт, объём другой биржи,
прогнозная свеча или текущая незакрытая цена. Запросы выполняются последовательно,
не чаще трёх в секунду, без авторизации и с ограниченным числом повторов.
Ограничения доступа не обходятся другим доменом, прокси или ключами.

Состав не меняется: BTC, ETH, BNB, XRP, ADA, LTC, BCH, LINK, DOGE к USDT.
OKX-история с 2023 года служит прогревом перед 2024. Нельзя дорисовать BNB
до его листинга, удалить неудобный актив или сократить период после результата.
Отсутствие любой нужной даты делает полный перенос непроверенным.

## Периоды и исполнение

Отдельно рассчитываются 2024 год, непрерывный январь2025–август2026 и
непрерывный январь2024–август2026. Сегменты календарного года извлекаются из
той же кривой без восстановления капитала в январе. Независимо начатые счета
разных периодов не склеиваются в один.

Исполнение — прежний `annual_rotation.model.simulate`: еженедельный пересмотр,
данные закрытия D−2 для open дня D, комиссия0.1% и неблагоприятное проскальзывание
0.05% с каждой стороны. Это единый сценарий, не личные исторические тарифы
пользователя. Шаг количества, минимальный номинал и ограничение доли прошлого
дневного объёма также остаются сценарными. Цены дневного открытия плюс заданное
отклонение не доказывают доступность реального исполнения в стакане.

В полном OKX-варианте дополнительно проверяются удвоение комиссии и проскальзывания,
дополнительный день задержки и счёт1000USDT на обоих длинных периодах. Итого18
расчётов. Остатки ниже минимального ордера не списываются молча: прежние флаги
неполноты и `return_pct=null` сохраняются. Отдельная проверка денежных потоков
учитывает стоимость оставшихся монет, не придумывая их продажу.

## Воспроизведение

В полном репозитории:

```bash
python -m pip install -r research/btc_flow/requirements.txt
python -m pytest -q tests/test_rotation_venue*.py
python -m research.rotation_venue_transfer.data --out okx-data-new
```

Новая загрузка получает свой manifest и может отличаться от исторически
проверенного снимка. Для точного повторения итоговых хешей нужны исходные
страницы из вычислительного пакета, а не вновь скачанные данные.

Из распакованного пакета `rotation-transfer-research-evidence`:

```bash
cd delivery
python -m pip install -r requirements.txt
python -m pytest -q tests/test_rotation_venue*.py
python -m research.rotation_venue_transfer.study \
  --binance ../prior/rotation-data \
  --okx ../new-source/okx-data \
  --prior ../prior \
  --out ../transfer-replay-new
```

Каталог вывода должен быть новым. Код проверяет хеш зафиксированной политики,
побайтное равенство прежнего симулятора, контрольный результат PR127 и поддержку
признаков до начала оценки. Выходы: полный JSON, таблицы всех18 расчётов,
календарные результаты, сравнение рыночных источников и отдельные журналы fills
и equity каждого счёта. Это не команда запуска торговли.

## Граница финансового вывода

Другая площадка — новые наблюдения цен и оборота, но не независимые рыночные
события. Времена 2024–2026 уже исследовались ранее; текущий состав активов
сохраняет смещение в пользу выживших монет. Повторный расчёт на чистом runner
проверяет воспроизводимость кода, а не существование экономического преимущества.

Положительный результат переноса не обещает прибыль завтра, регулярный месячный
доход или500% годовых. Налоги, хранение, риск контрагента, отвязкаUSDT и постоянные
расходы не включены. Продолжение исследования не включает разрешение на реальное
плечо, биржевые ордера, активацию планировщика или перезапись заблокированных
управляющих модулей. Численные результаты и фактически прошедшие проверки
публикуются отдельно после выполненного расчёта.
