# BTC Spot Regime — research only

Новая проверка запроса «500% или хотя бы прибыльное»: BTCUSDT spot, long/cash,
без плеча и коротких позиций. Это НЕ прежний минутный/секундный BTC Pressure,
и не обещание годового результата. Реальных ордеров и подключения к runtime нет.

## Зафиксированная модель

Основной `ensemble_1d` — большинство трёх дневных состояний:

1. EMA10 выше EMA50 и цена закрытия выше EMA50.
2. Вход выше максимума предыдущих 55 дней, выход ниже минимума предыдущих 20 дней.
3. Закрытие выше цены 63 дня назад и выше SMA200.

Два голоса из трёх -> владеть BTC; иначе USDT. Между переключениями количество
BTC не увеличивается. Каждый сигнал использует только закрытую свечу; базовое
исполнение — на часовом open ещё через полный час после доступности сигнала.
Нет стопа по ATR или постоянно забираемого маленького тейка: идея удерживает
тренд до смены состояния. Это не частый скальпинг.

Ещё девять заранее определённых компараторов позволяют сравнить часовые,
четырёхчасовые и дневные EMA/каналы/моментум/короткую покупку отката. Параметры
в `protocol.json` опубликованы до расчётов, commit
`79d5c8081359436cd5e417c0239a5c3898e9bd13`.

Один дополнительный кандидат выбирается только по 2020–2023: положительный CAGR
к максимальной просадке (знаменатель не меньше 10%), минимум 12 закрытых сделок,
без неоценённых пробелов при удержании. Проверки 2024 и 2025–август2026 не
меняют выбор. Первичный ансамбль фиксирован и не зависит от этого отбора.
Все десять поздних результатов сохраняются, даже если первичный проиграет.

## Данные и бухгалтерия

104 месячных официальных Binance spot 1h архива за январь2018–август2026,
проверка опубликованных CHECKSUM и фиксация SHA-256. 2018–2019 — прогрев.
Миллисекунды/микросекунды нормализуются; пропуски цен не заполняются. Пробел
сбрасывает историю индикаторов. Неполная агрегированная свеча не становится
закрытой. Неизвестная цена при удержании делает доходность непригодной для
финансового вывода, даже если известные денежные потоки удалось сверить.

Счёт $1000, номинал в USDT. Базово покупка максимум на весь доступный cash с
учётом комиссии; ни заёмных денег, ни усреднения. Комиссия .1% и slippage .05%
на каждую сторону — допущения исследования, не исторически подтверждённый
тариф аккаунта. Заявка округляется вниз по шагу .00001 BTC, минимум $10;
объём выше .1% предшествующего часа отклоняется. Это сценарные биржевые фильтры.

Фьючерсный funding и заёмный процент отсутствуют потому, что модель торгует
полностью оплаченным спотовым BTC, а не потому, что забыты расходы деривативов.
USDT-счёт не зарабатывает процент. Налоги, инфраструктура, риск хранения,
контрагента и отвязки USDT не включены. Изменение стопового риска раскрыто ниже.

## Риск — не тот же самый, что у прежнего скальпера

100% спотовая доля без плеча НЕ равна риску .25% на сделку. Основной медленный
вариант не обещает просадку до 10% и не использует прежний постоянный выключатель
7%. Реальную моделируемую просадку нужно читать рядом с доходностью.

Поэтому отдельно считаются: покупка на 25% cash при входе; постоянная остановка
при DD7% без перезапуска; удвоение комиссии и slippage; задержка24ч. У доли25%
прибыльный BTC впоследствии может занимать более 25% капитала, поскольку внутри
позиции ребалансировки нет. Выключатель может быть перескочен гэпом. Стоп считается
по предыдущему закрытому часовому максимуму equity, не будущему внутрибара.

Дополнительная стоимость на тех же исполнениях — арифметическая чувствительность,
не отдельный исполнимый счёт. Buy-and-hold и cash — обязательные ориентиры.
Положительная прибыль сама по себе не означает превосходство над рынком.

## Периоды и проверка

Разработка2020–2023, validation2024, затем непрерывный2025–август2026 на одном
счёте. Годовые reset-диагностики не соединяются в общую кривую. История уже
использовалась исследовательской программой, включая август: нет pristine
holdout. Многолетние +500% не выдаются за +500% годовых. Короткие периоды не
получают CAGR. Bootstrap по блокам30д — исследовательская неопределённость,
не прогноз и не поправка за многочисленные прошлые попытки.

Расчёт и тесты выполняются в GitHub Actions: локальные инструменты этой сессии
недоступны. Второй чистый runner повторяет весь расчёт на тех же проверенных
байтах; это независимое исполнение того же кода, не независимая реализация модели.
Отдельно сверяются покупки/продажи, остатки cash/BTC и закрытые сделки.

```bash
python -m pip install -r research/btc_flow/requirements.txt
python -m pytest -q tests/test_btc_spot_regime.py
python -m research.btc_spot_regime.study --data spot-data --out spot-report --download
```

В выгруженном CI-пакете используйте `spot-delivery/requirements.txt` и запускайте
команды из `spot-delivery`; сами данные находятся рядом в `spot-data`.
Каталоги должны быть новыми: результаты не перезаписываются. Выходы содержат
все сигнальные модели, отбор, доходности, сделки, исполнения и часовые equity.
Точные результаты публикуются только после фактического завершения вычисления.
