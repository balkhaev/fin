# Active V18–V25 — return enhancement research

This directory archives eight return-enhancement experiments applied to the frozen Active V8 foundation. The purpose is to preserve negative evidence and prevent the same ideas from being re-tested or promoted after relaxing the acceptance gates.

All candidates use completed daily information and next-UTC-open execution. The formal ranking excludes January–June 2026, though that interval is not pristine at the overall research-program level.

**Decision:** no candidate passed every predeclared profitability, tail-risk, cost and turnover gate. Active V8 remains the growth benchmark. V24 is the strongest near-candidate but remains rejected.
