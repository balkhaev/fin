# Ограниченный бюджет каналов и комбинация с относительным трендом

Этот этап объявлен после просмотра результатов дневных каналов: положительная
доходность сопровождалась слишком большой просадкой. Это последующий опыт
на той же известной истории, а не независимый скрытый тест.

Пять конфигураций зафиксированы до нового расчёта:

| Имя | Целевые позиции при новом входе |
|---|---|
| `relative125` | Прежняя относительная пара с суммарным номиналом 1,25×. |
| `daily25` | Четверть исходных дневных канальных целей BTC+ETH. |
| `daily50` | Половина тех же целей. |
| `mix25` | 75% относительных целей с исходным номиналом 1× + 25% дневных целей с номиналом 1×. |
| `mix50` | По половине тех же относительных и дневных целей. |

Основной вариант заранее — `mix25`. Он не заменяется лучшим числом другого
варианта после просмотра результата. Контроль имеет иной риск и больший
входной номинал; сравнение не называется автоматически равнорисковым.

Это не сложение доходностей независимых счетов. Цели взаимно зачитываются
в знаковое количество двух инструментов, а затем старый механизм заново
исполняет сделки, списывает комиссии и учитывает funding на одном счёте.
Изменение веса смеси при прежних знаках само по себе не вызывает мгновенную
перебалансировку в существующем механизме: количества сохраняются до выхода.
Поэтому запрошенное соотношение не выдаётся за непрерывно поддерживаемое.

Меньший целевой размер — не фиксированный предел убытка. Рынок меняет
номиналы и капитал; фактический дрейф сохраняется в аудите. Нет мартингейла,
замены источника цен, подбора новых входных порогов или исправления старого
расчётного ядра. Смена бюджета выполняется до расчёта сделок, а не как
масштабирование готовой кривой прибыли.

Выполняются 43 сценария: все пять вариантов на полной истории, отдельном
2024, позднем счёте, при удвоенных расходах и дополнительной задержке.
Основной вариант и контроль также проходят дорогие сделки на полном
периоде, поздний счёт с 1 000 USDT и семь фиксированных годовых стартов.
Все отрицательные результаты и неполные случаи сохраняются, не заменяются
другими параметрами.

## Воспроизведение

```bash
python -m pip install -e . -r research/btc_flow/requirements.txt
python -m pytest -q tests/test_channel_budget.py
python -m research.channel_budget.study \
  --source /path/to/unpacked/Opportunity_Leverage_Research \
  --channel-evidence /path/to/channel-scale-artifact \
  --out /path/to/new-budget-results \
  --allow-archived-reference
```

`--channel-evidence` должен содержать исходный `report/results.json`
предшествующего канального опыта с зафиксированным хешем. Этот вход нужен
для проверки тождества модели/данных, а не для адаптации нового размера
по её будущему результату. Все новые веса заданы в протоколе.

В main публикуются новый конечный исследовательский код, тесты и сохранённые
результаты. Прежнее архивное ядро с известной ошибкой пропущенной mark price
не переносится, не исправляется и не становится готовым к реальным деньгам.
Его явное историческое использование требует точного проверенного архива.
Рабочие стратегии, реальные ордера и планировщик не затрагиваются.

Полные таблицы и общий отчёт трёх этапов — в
`research/holding_horizon/RESULTS_RU.md`; машинная сводка —
`research/holding_horizon/verified_summary.json`. Более высокая доходность
одного периода не доказывает будущую стабильность. История переиспользуется,
а реальное исполнение, налоги, инфраструктура и контрагентские риски остаются
ограничениями. Никакого подтверждения 500% годовых это описание не содержит.
