# BTC Flow Continuous

Новый исследовательский модуль проверки согласованности spot/perpetual потока
Binance. **Не является секундной BTC Pressure, не заменяет её, не отправляет
биржевые ордера. Доказанных +500% в год здесь заранее не предполагается.**

## Заранее фиксированный эксперимент

Протокол опубликован до расчётов: `6d61de52a79e91a77769e3a0d4e4bd28491a036f`.
54 варианта: 3 семейства × окна потока 1/5/15 минут × пороги 0.10/0.25 ×
профили выхода quick/intraday/runner. Предыдущие правила BTC Pressure не меняются.

Семейства:
1. `confirmed_breakout`: спотовый и фьючерсный дисбаланс исполненных taker-сделок
   подтверждают пробой прежнего 20-минутного диапазона.
2. `spot_absorption`: поток spot противоположен perp, текущая закрытая свеча
   разворачивается в сторону spot ниже/выше 60-минутного VWAP.
3. `perp_exhaustion`: сильный фьючерсный импульс не подтверждён spot, отклонение
   basis от прошлого среднего значительно, закрытая свеча разворачивается.

Это минутные проверяемые признаки, не доказательство реального «поглощения»
скрытыми участниками. Дисбаланс вычисляется из quote volume фактических taker
покупок/продаж; прогнозируемые будущие сделки не используются.

Период загрузки: январь 2022 — июль 2026 включительно. 2022–2023 используются
для выбора одного представителя каждого семейства; 2024 — validation. Финалист
фиксируется перед расчётом 2025–июль2026. Все эти периоды уже просматривались в
других исследованиях: поздняя проверка здесь REUSED, не pristine OOS.

Стратегии должны показать плюс/PF>=1.1 во всех периодах отбора, не меньше 300
сделок в 2022–2023 и 100 в 2024. При отсутствии допуска лучший диагностический
финалист явно маркируется REJECTED, а критерии не снижаются. Поздняя история
не используется для выбора параметров. Сохраняются все 54 исходных результата.

## Исполнение и счёт

Один счёт $1000, риск 0.25% на сделку, начальная экспозиция не больше 2x,
дневной выключатель -1%, постоянный -7% от максимума. Эти величины — допущения
эксперимента, не подтверждённые ограничения реального счёта пользователя.
При гэпах предел просадки может быть превышен. Следующий день не снимает
постоянную остановку. Основная поздняя проверка НЕ сбрасывает капитал в январе.
Независимые годовые счета дополнительно приводятся с явной меткой reset.

Сигнал по закрытой минуте, taker-вход на следующем open. Stop-first при неизвестном
порядке экстремумов свечи, неблагоприятный gap учитывается, выгодный gap на тейке
не приписывается. Trailing меняется только для следующей минуты. Одна позиция,
нет усреднения и удвоения. Шаг 0.001 BTC, минимум $100 и участие <=0.1% объёма
прошлой минуты — сценарные ограничения, не исторически восстановленный exchangeInfo.

Базовые расходы: 0.05% taker с каждой стороны, 0.01% slippage с каждой стороны.
Это единый сценарий по всему периоду, не доказанный исторический VIP-тариф.
Фильтр входа фиксирован по базовым расходам и не ужесточается в стрессах;
размер позиции и траектория исполнения при изменении расходов могут различаться.
Дополнительно: удвоенная комиссия, удвоенный slippage, +1 минута задержки и
нулевые комиссии/slippage только как недоступная диагностическая абляция.

## Funding и точность данных

220 месячных архивов официального Binance Data Collection: spot klines,
perpetual trade klines, mark-price klines, фактически рассчитанные fundingRate.
Проверяются опубликованные CHECKSUM/SHA-256 и полный состав файлов. Spot
после января 2025 использует микросекунды; единицы времени нормализуются.
Пропуски spot НЕ заполняются: они запрещают вход до восстановления окна признаков.
Разрыв фьючерсных минут останавливает расчёт целиком.

Запрос точных settlement marks через официальный REST вернул HTTP451. Отказ
сохранён без обхода. Фактическая ставка берётся из исторического fundingRate,
но размер платежа в этой версии использует OPEN минутной mark-price свечи.
**Это приближение settlement mark, не точный платёж реального аккаунта.**
При отсутствии mark в минуте удерживаемого начисления пригодная доходность null.
Ticker forecast не подставляется вместо рассчитанной ставки.

Дополнительная худшая mark-цена внутри минуты начисления пересчитывается на
ТОЧНО ТЕХ ЖЕ исполнениях как чувствительность. High/low не доступны в начале
минуты и не используются для входа, размера позиции или управления. Эта оценка
не является другой причинной стратегией и не доказывает исторический максимум DD.

## Проверка и воспроизведение

Локальные инструменты исполнения в этой попытке недоступны. Расчёты и тесты
выполняются в конечном read-only GitHub Actions, с проверкой логов и artifacts.
Это не «локальные тесты плюс независимый CI»: двух независимых сред пока нет.
Отдельная арифметическая проверка пересчитывает экспортированные сделки через
side × qty × (exit-entry) − fees − funding, сверяет объём и время исполнения.

Python3.13 и зависимости из `research/btc_flow/requirements.txt`:

```bash
python -m pip install -r research/btc_flow/requirements.txt
python -m pytest -q tests/test_btc_flow_continuous.py
python -m research.btc_flow_continuous.download --out continuous-data
python -m research.btc_flow_continuous.study --data continuous-data --out continuous-report
```

Выходы: `data_audit.json`, `all_54_training.json`, `selection.json`,
`annual_returns.csv`, `continuous_results.csv`, все сделки и дневные кривые
капитала финалиста, `results.json`, `summary.json`. Новые каталоги обязательны;
старые результаты не перезаписываются. На биржу не отправляется ничего.

Численный итог публикуется отдельно после выполненного расчёта. Успешные
программные тесты не доказывают ни прибыльность, ни будущий годовой результат.
