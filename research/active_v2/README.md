# Active research v2

Вторая итерация после отрицательного AIMR v1. Цель — не косметически оптимизировать провальный 5-минутный momentum, а проверить две независимые гипотезы с меньшим оборотом.

## Семейства

### 1. Rotation core

Активная 4-часовая ротация между BTC, ETH и cash:

- положительный быстрый и медленный momentum;
- цена выше EMA режима;
- выбор более сильного BTC/ETH;
- размер позиции по реализованной волатильности, без плеча;
- hysteresis против частых переключений;
- ensemble из трёх устойчивых соседних конфигураций.

### 2. Shock reversal

15-минутный long-only возврат после редкого падения:

- z-score многобарного падения;
- только положительный 4h режим;
- закрытие свечи в верхней части диапазона;
- фильтры quote volume и taker-buy ratio;
- вход на open следующей свечи;
- stop-first, если одна OHLC-свеча касается стопа и цели;
- риск 0,5% счёта, максимум 50% капитала в одном инструменте.

## Разделение выборки

- development: 2020-01-01 — 2023-01-01;
- validation: 2023-01-01 — 2025-01-01;
- research holdout: 2025-01-01 — 2026-07-01.

Holdout не называется полностью нетронутым: общий режим рынка 2025–2026 уже наблюдался при диагностике AIMR v1. Он не участвует в выборе параметров v2, но окончательное доказательство возможно только на future paper-forward данных.

## Издержки

- low: 5 б.п. на сторону;
- base: 10 б.п. на сторону;
- stress: 20 б.п. на сторону.

Это единая all-in оценка комиссии, спреда и проскальзывания. Для shock-reversal свечи не дают модель очереди лимитных заявок или L2 adverse selection.

## Запуск

```bash
python -m pip install -r research/active_v2/requirements.txt
python research/active_v2/run_research.py --self-test
python research/active_v2/run_research.py \
  --output artifacts/active_v2 \
  --cache .cache/binance_vision_15m
```

Положительный исторический статус означает только `promising_research_candidate`. Перед реальными деньгами обязательна неизменяемая paper-forward проверка.
