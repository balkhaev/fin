# V469–V476 — frontier barbell ensemble

V461 exposed a clean development frontier rather than a single dominating policy:

- constant 40/60 mix: strongest risk-adjusted control;
- persistent budget: almost identical Sharpe with lower drawdown;
- 22% volatility target: highest development CAGR.

V469 freezes several simple convex combinations of these already-defined implementations. No new market feature, state threshold, lookback or alpha parameter is introduced. Selection uses 2021–2023 and the 2022/2023 walk-forward folds; 2024–2026 H1 are opened once after the selection proof.

The result is exploratory because the underlying component histories were known before this cycle.
