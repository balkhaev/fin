# fin

Репозиторий воспроизводимых исследований торговых алгоритмов.

Цель — сохранять код, предположения, происхождение данных, отрицательные и положительные результаты, чтобы не повторять уже проверенные ошибки и не выдавать переобучение за рабочую стратегию.

## Правила исследования

- сигнал исполняется не раньше следующей свечи;
- комиссии и проскальзывание учитываются с обеих сторон;
- development, validation и research holdout разделяются заранее;
- отрицательные результаты не удаляются;
- прибыльность без устойчивости к соседним параметрам и стрессу затрат не считается edge;
- реальная торговля запрещена до paper-forward проверки.
