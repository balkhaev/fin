# DYN-IV113: предзарегистрированные shadow-профили

Базовый профиль `DYN-IV113` не изменён. Добавлены два отдельных профиля с
независимыми identity и snapshot-файлами:

- `risk50` / `DYN-IV113-RISK50`: целевая волатильность 50%;
- `band2` / `DYN-IV113-BAND2`: deadband целевых весов 2 процентных пункта.

Оба профиля имеют `mode=shadow` и запускаются только при явной настройке:

```text
FIN_DYN_SHADOW_PROFILES=risk50,band2
```

Без этой переменной стек продолжает запускать только неизменённый базовый
paper-профиль. Наличие shadow-профилей в `main` не разрешает реальный капитал и
не переносит метрики исследовательского окна на forward-счёт. Для сравнения
следует хранить отдельные snapshots и не менять параметры до завершения заранее
выбранного forward-периода.
