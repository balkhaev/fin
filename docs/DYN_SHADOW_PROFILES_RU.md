# DYN-IV113: предзарегистрированные shadow-профили

Baseline `DYN-IV113` не изменён. Добавлены два отдельных профиля с независимыми
identity и snapshot-файлами:

- `risk50` / `DYN-IV113-RISK50`: target volatility 50%;
- `band2` / `DYN-IV113-BAND2`: target deadband 2 процентных пункта.

Оба профиля имеют `mode=shadow`. Они запускаются только при явной настройке:

```text
FIN_DYN_SHADOW_PROFILES=risk50,band2
```

Их наличие в `main` не является разрешением реального капитала и не переносит
метрики исследовательского окна на forward-счёт. Для сравнения следует хранить
отдельные snapshots и не менять параметры до завершения заранее выбранного
forward-периода.
