# Atlas NX R1 — восстановление под новой identity

Статус: `validated paper/shadow reconstruction`.

`atlas_nx_r1` не является побайтово точным `v75_atlas_nx`. Полная история
репозитория содержит спецификации и исходники его компонентов, но не содержит
точный V75 target producer и regression-equity с закреплёнными SHA-256. Поэтому
старые метрики V75, его high-water и forward-состояние не переносятся.

## Что реализовано

- V27-слой: причинный long-only momentum по окнам 63/126/252 дня,
  inverse-volatility и top-3 из исходной вселенной;
- V4-слой: защитный ансамбль breadth, dual momentum и Donchian для BTC/ETH;
- V67-слой: лимиты accelerator сохранены, но permission равен нулю без
  on-chain публикации не старше 48 часов;
- необратимый high-water ratchet `1.75x / 2.50x`;
- V4-веса `0% / 10% / 20%`, gross caps `1.10x / 1.05x / 1.00x`;
- volatility throttle `1.00 / 0.75 / 0.50` на порогах `25% / 35%`;
- сигнал закрытия дня применяется не раньше следующего дня;
- paper-комиссия 40 bps на оборот, live-mark по текущей свече Binance;
- отдельный счёт `$10,000`, новый forward clock с `2026-07-29`;
- никаких API для отправки биржевых ордеров.

Если актив из исходной вселенной перестал публиковать свечи, он исключается из
новых целей fail-closed, а worker продолжает работать при наличии минимум семи
актуальных рядов. На момент восстановления это относится к `EOSUSDT`.

## Проверка

Миграционная запись: `ATLAS_NX_R1_MIGRATION.json`. Детерминированный regression
fixture закрепляет веса, NAV, число paper-исполнений, risk stage и volatility
multiplier. Отдельные тесты проверяют причинность последней свечи, необратимость
ratchet, stale on-chain и исключение delisted-актива.

Исторические показатели V75 разрешено показывать только как справку о
предшественнике, но не как результаты Atlas NX R1.
