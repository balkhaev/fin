# FIN Research — публикация результатов в main

## Что входит в этот выпуск

Отдельная страница `frontend/research.html` доступна рядом с операторским
`live.html`. Это статическая витрина уже рассчитанной истории, не новая
стратегия, не paper-счёт и не исполнение ордеров. В неё включены все 15 вариантов
из последнего набора PR #134, три независимых начальных периода, годовые
сегменты, расходы, funding, фактический дрейф номинала и сравнительные кривые.
Исходная `old_pair_1x` закреплена первой и присутствует на каждом графике.

По умолчанию открыт полный период 2021 — август 2026, а не более удачные
поздние 608 дней. Выбор `runner720_125x` означает начальный объект сравнения,
не инвестиционную рекомендацию или назначение победителя. Отрицательные годы,
отсутствующие стрессы и неполный 2026 год показаны явно. Значение «Не рассчитано»
не заменяется нулём. 500% годовых не доказаны.

График капитала использует настоящие дневные закрытия сохранённой часовой
кривой. График просадки сохраняет минимум фактических часовых mark-закрытий
внутри каждого дня, поэтому худшее значение не исчезает при визуальном
укрупнении. Это не тиковый расчёт ликвидации или предел внутридневного риска.

## Граница слияния

В main выпускаются только интерфейс, экспорт сохранённых результатов, статические
данные, документация и тесты. Исследовательское расчётное ядро
`research/relative_futures/account.py` с известным дефектом `0 * NaN`
не переносится из draft PR #134. Его исправление, переименование или
альтернативная реализация не выполнялись. Все экспортируемые числа получены
ранее на отдельно проверенном полном снимке, но это не делает ядро пригодным
для новых данных с пропусками.

Сервер, брокер, планировщик, настройки риска, биржевые ключи и код работающих
paper-стратегий не изменяются. В существующем `live.html` добавлена только
ссылка «Исследования». Новая страница отправляет один same-origin GET за
статическим JSON, не использует WebSocket, POST или биржевые API.
Кнопки запуска, применения параметров и разрешения торговли отсутствуют.

## Источник и воспроизведение

Источник — artifact **9991153959** из run **34039211921** репозитория `balkhaev/fin`.
SHA-256 архива:
`a4f8bf2842ad8550a95353b983231b5f08f541153566bf0e262c39105a67d9af`.
Экспортёр проверяет канонические SHA трёх первичных результатов — 63, 56 и
28 сценариев — до чтения метрик и графиков. Всего 147 пересекающихся расчётов,
не 147 независимых рынков. Проверенные снимки зафиксированы в обычных файлах
`frontend/data/research-evidence.json`, `research-comparison.csv` и
`research-manifest.json`; они доступны без GitHub API, истечения CI artifact
или повторного запуска эксперимента.

```bash
# Из полного клона и распакованного точного источника:
python scripts/build_research_showcase.py --source /path/to/evidence --repo .
python -m pytest -q tests/test_research_showcase.py
python -m http.server 8000 --directory frontend
# Открыть http://127.0.0.1:8000/research.html
```

Экспорт не импортирует ни одной торговой реализации из `research` и не
обращается к сети. Добавление навигации при первой публикации — явный параметр
`--link-navigation`; оно идемпотентно и прекращается, если известная точка
вставки изменилась.

Сборка контейнера по существующему Dockerfile копирует frontend как обычные
файлы. Рабочий сервер должен отдавать страницу тем же статическим маршрутом,
что остальные экраны. Наличие коммита в main само по себе не доказывает
доступность нового файла на публичном домене: развёртывание проверяется отдельно.

## Контроль качества

Проверяются хеши источника, 45 базовых сочетаний варианта/периода, совпадение
последней точки кривой с конечным капиталом и сохранение часового минимума
просадки. Дубли времени, NaN, несовпадение дат и непригодные исходные результаты
останавливают публикацию. Данные не чинятся и не подгоняются экспортом.

Браузерный прогон Chromium проходит все 45 сочетаний, оба режима графика,
отрицательные годы, отсутствие отдельного стресс-сценария, ошибку HTTP,
недопустимый JSON и повторную загрузку. Сохраняются настоящие снимки desktop,
768px и 390px; проверяется отсутствие горизонтального переполнения страницы.
Работа новой страницы не требует внешних шрифтов, CDN или npm в production.

Это выпуск интерфейса и доказательств, не новое улучшение торговой доходности.
Ранее полученные 59.33% за 608 дней у 1.25x не превращаются ни в 59.33% ежегодно,
ни в доказанные будущие результаты. Выбор параметров и история исследований
содержат повторное использование тех же рыночных событий. Реальные исполнения,
налоги, инфраструктура, контрагент и риск USDT не моделируются полностью.
