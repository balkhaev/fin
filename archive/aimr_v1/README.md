# AIMR v1 — отрицательный контроль

Первая реализация 5-минутного BTC/ETH momentum + shock mean-reversion сохранена намеренно, несмотря на отрицательный результат.

Базовый research holdout:

- 285 сделок;
- доходность −24,36%;
- максимальная просадка −25,14%;
- profit factor 0,45;
- momentum был отрицательным даже до полной стоимости исполнения;
- mean-reversion был существенно лучше, но не перекрывал реалистичные расходы.

Полный разбор находится в `ANALYSIS_RU.md`, таблица прогонов — в `metrics.csv`. Исходный код AIMR v1 остаётся зафиксирован в draft PR `balkhaev/trader#4`; новая читаемая реализация v2 находится в `research/active_v2` этого репозитория.

Эта версия не предназначена для торговли; она служит отрицательным тестом и защищает от повторения уже проверенной ошибки.
